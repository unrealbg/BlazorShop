About BlazorShop

A practical .NET commerce starter

A layered commerce application with a server-rendered public storefront, Blazor workspace, ASP.NET Core APIs, PostgreSQL, Stripe, Docker and Aspire.

Storefront

Discoverable by design

Stable product and category routes give public catalog content real HTML, metadata and structured data without sacrificing the interactive customer workspace.

Workspace

Operations stay focused

Account and admin experiences are separated from the public storefront so customer operations, catalog management and security-sensitive flows remain explicit.

Architecture

Opinionated, not over-engineered

BlazorShop is designed as a modular .NET commerce starter rather than a collection of disconnected demos. The UI contract follows the real feature surface and Commerce Core roadmap.

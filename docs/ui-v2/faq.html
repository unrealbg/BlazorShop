Frequently asked questions

Quick answers about products, ordering, accounts and the public storefront.

Why do products have dedicated pages?

Published products use stable server-rendered routes so customers and search engines can reach the same canonical product content.

Can I use the admin area?

Admin access is role-protected. The UI exposes management surfaces only to authorized users.

What payment methods are available?

The current application supports Stripe card payments, cash on delivery and bank transfer where enabled.

How do I track an order?

Open Account → Orders. When tracking information is available, the order detail displays the tracking number or carrier URL.

Do all catalog items appear publicly?

No. Only products intended for public discovery should appear on storefront routes.
